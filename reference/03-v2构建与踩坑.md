# 工程手册：构建、图标、诊断与踩坑（v1.0.0 交付版）

> 原理与方案见 `01-底层原理与接口依赖.md`、`02-可行性分析与实现方案.md`（尤其第 6 节）。
> 本文只记录**怎么把源码重新变成 exe**、诊断工具怎么用、以及踩过的坑。

## 2. 构建环境

系统里 WorkBuddy 内嵌的 Python 3.13 **不带 tkinter**，因此用本机
`uv` 提供的 CPython 3.12.13 建独立 venv：

```bash
PY="C:/Users/Figo/AppData/Roaming/uv/python/cpython-3.12.13-windows-x86_64-none/python.exe"
"$PY" -m venv tools/.buildenv
"tools/.buildenv/Scripts/python.exe" -m pip install \
    pywin32 pyinstaller pystray pillow svglib reportlab pypdfium2 psutil \
    -i https://pypi.tuna.tsinghua.edu.cn/simple
```

依赖用途：`pywin32` → WMI COM；`tkinter` → GUI；`pystray` + `Pillow` → 托盘；
`svglib`/`reportlab`/`pypdfium2` → SVG 图标；`psutil` → 端到端测试管理进程树。

## 3. 生成图标（用户指定 `reference/电池.svg`）

```bash
"tools/.buildenv/Scripts/python.exe" tools/svg_to_ico.py
```

渲染链：`svglib` 解析 SVG → `reportlab` 生成 PDF → `pypdfium2` 光栅化 →
`Pillow` 合成 512×512 白色圆角底 + 透明四角 → 输出 ico（16–256 多尺寸）与 png。

为什么不走常见方案（均实测失败）：

| 方案 | 失败原因 |
|---|---|
| `cairosvg` | Windows 缺 `libcairo-2.dll` |
| `reportlab.renderPM` | 默认后端 `rlPyCairo` 不可用 |
| Edge `--headless --screenshot` | exit=0 但不产出截图（环境限制） |
| **svglib → PDF → pdfium2** | **成功**，纯 Python wheel，无系统库依赖 |

## 4. 打包命令

注意 `--add-data` 必须用 **Windows 风格绝对路径**（`pwd -W`），
Git Bash 的 `/c/...` 会被解析成 `\c\...` 而找不到文件。

```bash
cd "C:/Users/Figo/Desktop/Dev/荣耀电脑管家"
ROOT="$(pwd -W)"
PY="tools/.buildenv/Scripts/python.exe"
"$PY" -m PyInstaller \
  --onefile --noconsole --uac-admin \
  --name HonorBatteryGuard \
  --icon "$ROOT/dev/HonorBatteryGuard.ico" \
  --add-data "$ROOT/dev/HonorBatteryGuard.png;." \
  --add-data "$ROOT/dev/HonorBatteryGuard.ico;." \
  --distpath "$ROOT/releases/HonorBatteryGuard" \
  --workpath "$ROOT/temp/build_v4" \
  --specpath "$ROOT/temp/spec_v4" \
  --hidden-import win32com.client --hidden-import pythoncom \
  --hidden-import pystray._win32 \
  "$ROOT/dev/HonorBatteryGuard.py"
```

- `--uac-admin` 内嵌 `requestedExecutionLevel=requireAdministrator`（可用
  `bytes.find(b'requestedExecutionLevel')` 在 exe 里核对）。
- **png 与 ico 两个资源都必须 `--add-data`**：`--icon` 只写进 exe 的 PE 资源
  （供资源管理器/快捷方式显示），**不会**出现在 `sys._MEIPASS`。v2.1 只带 png，
  运行时读 ico 必然失败，窗口图标回退成 Tk 羽毛图标。
- 偶发 `PermissionError(13)` 追加 PKG（Defender 短时占用），PyInstaller 会自动重试；
  换全新 `--workpath` 也可规避。

## 6. 踩坑清单

1. **`u8Input` 必须 64 字节**，8 字节返回「无效的参数」。
2. **COM 参数必须显式 `VARIANT(VT_ARRAY|VT_UI1, list)`**；直接传 `list` / `bytes`、
   或 `o.OemWMIfun(...)` / `svc.ExecMethod(path, ...)` 都失败；只有 `ExecMethod_` 可用。
3. **`\SBCM` 的 byte[3] 是 EC 的 `dact` 寄存器，不是魔数**：填 0x48 会把 dact 改写，
   必须从 `\GBCM` 读回原值再原样带回（探测中已写回 0 恢复）。
4. **关闭荣耀电脑管家会把 EC 阈值清零为 0/100、mode=0**（详见 02 第 6 节）。
5. **非管理员 → 所有 WMI 操作「拒绝访问」**，连状态区都空；exe 用 manifest 提权解决。
6. **`BatteryStatus.Charging` 不可靠**，AC 在线时常为 True；用 `ChargeRate=0` + 容量趋势。
7. **停充后容量会自然下降**，趋势判定不能用 `|delta| ≤ 2`，否则误判 UNKNOWN。
8. **Windows 11 会折叠新托盘图标**，`NIM_ADD` 成功也不代表主托盘区可见；
   必须提供任务栏按钮等确定可见的入口。
9. **pystray `Icon.run()` 文档要求主线程**；本项目在 daemon 线程运行并验证
   `NIM_ADD` 成功、`visible=True`；退出时须调用 `icon.stop()` 结束消息循环。
10. **`--noconsole` 下 `sys.stdout is None`**，CLI 输出必须同时落盘
    （`last-cli-output.json`）才能验证。
11. **Git Bash 路径**：`pwd` 给 `/c/...`，传给 PyInstaller 的 `--icon` / `--add-data`
    要用 `pwd -W` 得 `C:/...`。
12. **开发环境程序黑名单**：`csc.exe` / `Add-Type` / `schtasks.exe` / `reg.exe` / 从 Bash
    调 `powershell.exe` 均被拦。因此不编译 C#、不用任务计划程序，
    注册表操作改走 Python `winreg`（不是绕过，是换用可验证的实现）。
13. **`powercfg /batteryreport /xml`** 才能稳定取到设计容量（本机 `BatteryStaticData`
    无实例、`Win32_Battery.DesignCapacity` 为空；实测 92041 mWh）。
14. **★ 窗口图标 ≠ exe 图标**：`--icon` 只作用于 PE 资源，Tk 窗口图标由窗口自身决定；
    `iconbitmap(default="")` 会**清空**它并回退到蓝色羽毛。必须把 ico 作为运行时
    `--add-data` 资源、用 `iconbitmap(path)` + `WM_SETICON(ICON_SMALL/ICON_BIG)`
    （`LoadImageW(LR_LOADFROMFILE)`，16 与 32 两种尺寸）显式设置。
    只对 `winfo_id()` 发消息不够——Tk 顶层是包装窗口，需先 `GetParent(hwnd)`。
    **v2.3 追加两条**：① 任务栏按钮对应的是 Tk **顶层** HWND，必须优先给它发 `WM_SETICON`，
    再补父窗口；② 必须在创建首个窗口前调用
    `SetCurrentProcessExplicitAppUserModelID(exe 路径)`，否则 Windows 按 Tk 默认 AUMID
    取图标，关闭再启动仍会回退成羽毛。两者缺一都会让任务栏图标在重开后变羽毛。
15. **★ ttk `vista` 主题忽略 `background` 但保留 `foreground`**：
    `style.configure("Accent.TButton", foreground="#fff", background="#4f46e5")`
    会变成浅底白字、完全看不见。主按钮改用经典 `tk.Button` 显式 `bg`/`fg`。
16. **★ pystray 的 `checked` / `text` 是惰性描述符**：Windows 原生 HMENU
    只在 `update_menu()` 时重建，状态由菜单之外的动作改变后（例如主界面点
    「随系统启动」）**必须调用** `icon.update_menu()`，否则勾选永远显示旧值。
    另注意 `radio=True` 只在 `checked is not None` 时生效。
17. **`--tray` 启动时不要无条件 `withdraw`**：托盘初始化失败时窗口会彻底不可见、
    用户无法操作。必须先判断 `tray_icon` 是否可用，否则保持窗口可见并告警。
18. **测试脚本写配置要对准目标**：源码模式 `read_config()` 指向 `dev/`，
    exe 读的是 `releases/HonorBatteryGuard/`；跨进程测试要直接写 exe 同目录的 json，
    否则「配置了 hide_to_tray=True 却仍走默认行为」会被误判为功能 bug。
19. **★ 登录自启不能在 `HKCU\Run` 里做提权程序**：v2.1/v2.2 把
    `"exe" --tray` 写进 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，
    但 exe 内嵌 `requireAdministrator`，Run 项在登录时**不会自动弹 UAC、直接静默失败**，
    表现就是「随系统启动点了没用」。v2.3 改用**任务计划程序**：登录触发器
    `Triggers.Create(9)` + `Principal.RunLevel=1(HIGHEST)` + `LogonType=3`（交互式令牌），
    `RegisterTaskDefinition` 的 userId/password 传空字符串 `("", "", 3)` 避免
    `E_ACCESSDENIED`。这样登录时静默以最高权限启动、无 UAC 弹窗。
    （开发沙箱禁止 `schtasks.exe` 且 COM 写入被策略拦截，代码无法在本机自测创建，
    须在用户真实管理员机器上验证。）
